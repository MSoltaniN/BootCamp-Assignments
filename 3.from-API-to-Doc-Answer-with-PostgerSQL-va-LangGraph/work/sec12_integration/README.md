# بخش ۱۲ — یکپارچه‌سازی و آمادگی تحویل (۸ نمره)

## چه چیزی ساخته می‌شود

API نهایی که به SQLite بخش ۶ و گراف بخش ۱۱ وصل است، به‌همراه دروازهٔ رگرسیون و manifest تحویل. `TestClient` درخواست HTTP را در همان فرایند اجرا می‌کند؛ استقرار اینترنتی جزو اجرای مرجع نیست.

| ماژول | نقش |
|---|---|
| `adapter.py` | `SQLiteAdapter` برای پرونده/جلسه/پیام + `health` |
| `app.py` | endpoint پاسخ با schema ورودی، کنترل هویت/مالکیت و `invoke` گراف؛ خطای مجوز ⇒ ۴۰۳ |
| `negative.py` | چهار مسیر منفی: بدون هویت ۴۰۱، غیرمالک ۴۰۳، query کوتاه ۴۲۲، فیلد اضافه ۴۲۲ |
| `idempotency.py` | `POST` جلسه دوبار با کلید یکسان ⇒ یک `session_id`؛ برخورد با پروندهٔ دیگر ⇒ ۴۰۹ |
| `view.html` | نمای RTL حداقلی با `textContent` و escape برای متن مشکوک |
| `traces.py` | بازسازی ۸۰۰ trace از ۴۸۰۰ رویداد، نرخ خطای هر گام، p50/p95 مجموع latency |
| `gate.py` | regression gate: مالکیت، idempotency، نسخهٔ embedding، استناد، پاک‌سازی لاگ |
| `ci.md` | قرارداد pipeline: نصب، سرویس، migration، آزمون، توقف هنگام شکست، rollback، راز از env |
| `manifest.py` | manifest تحویل با hash فایل‌های کلیدی |

## زیرسؤال‌ها

۱۲٫۱ اتصال API به SQLite و سه درخواست پایه · ۱۲٫۲ endpoint پاسخ با trace ID · ۱۲٫۳ چهار مسیر منفی · ۱۲٫۴ idempotency سرتاسری · ۱۲٫۵ نمای HTML و escape · ۱۲٫۶ traceهای observability و صدک‌ها · ۱۲٫۷ regression gate · ۱۲٫۸ قرارداد CI/CD · ۱۲٫۹ اجرای نهایی `check_day3_db.py` · ۱۲٫۱۰ دستورالعمل بازتولید + manifest · ۱۲٫۱۱ rubric اجرایی برای تصحیح ایجنتیک · ۱۲٫۱۲ گزارش نهایی سه‌دسته

## تعریف انجام‌شده

- چهار مسیر منفی دقیقاً ۴۰۱/۴۰۳/۴۲۲/۴۲۲ می‌دهند و متن خصوصی پرونده در خطا نیست.
- `check_day3_db.py` وضعیت `passed` و کد خروج ۰ می‌دهد و عددهای ۱۲٫۹ از همان گزارش واقعی است.
- manifest با hash فایل‌های کلیدی ساخته شده و هیچ مسیر شخصی/رمز در آن نیست.
- گزارش نهایی سه دستهٔ «واقعاً اجراشده / fixture / اجرانشده» و پنج اقدام اولویت‌دار دارد.

## تله‌ها

- ۴۰۱ (بدون هویت) و ۴۰۳ (غیرمالک) را یکی نکن؛ تمایزشان در بخش ۳ و ۱۲ امتیاز دارد.
- latency این داده مصنوعی است؛ محدودیت تفسیر را بنویس.
- gate باید نتیجهٔ **واقعی** کنترل‌های قبلی را جمع کند، نه ادعا.
- JSON دانشجو به‌تنهایی معتبر نیست؛ باید با بررسی خودکار و نوت‌بوک تطبیق داده شود (۱۲٫۱۱).
