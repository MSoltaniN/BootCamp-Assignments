تکلیف ۳: از API تا پاسخ مستند با PostgreSQL و LangGraph
در انتظار
شرح تکلیف
در این تکلیف یک سامانهٔ پژوهش فنی می‌سازی: کلاینت API با قرارداد خطا، دیتابیس PostgreSQL با کنترل مالکیت، ورود اسناد با حفظ منشأ، embedding و بازیابی، ارزیابی بدون نشت test، مسیریاب عصبی و گردش‌کار LangGraph با پاسخ مستند. پایه، اسلایدهای جلسهٔ ۳ است. تمرین ۱۴۴ زیرسؤال و ۱۲ بخش دارد؛ ۴۸ زیرسؤال مفهومی (۲۴ نمره) و ۹۶ زیرسؤال عملی (۷۶ نمره).
- دریافت: از کارت «دیتاست» همین صفحه بستهٔ day3-student-pack.zip (داده‌ها، راه‌اندازی دیتابیس و راهنمای START_HERE.md) و PDF صورت تمرین را بردار. PDF همان سؤال‌های همین صفحه است برای مرور آفلاین؛ پاسخ را همین‌جا می‌نویسی، فرم HTML جدا نداریم.
- اجرا: START_HERE.md قدم‌به‌قدم می‌گوید چطور محیط پایتون و مدل embedding (یک‌بار دانلود، بعد آفلاین) را آماده کنی. دیتابیس فقط یک فایل SQLite است (day3.sqlite)؛ Docker و PostgreSQL لازم نیست. بذر مرجع ۲۰۲۶۱۰۱۵ است.
- نوت‌بوک: برای هر زیرسؤال سه سلول بساز: (۱) Markdown با عنوان «زیرسؤال ۵٫۳» و صورت سؤال، (۲) کد انگلیسی، (۳) تحلیل فارسی راست‌به‌چپ. تصحیح‌کننده با همین عنوان‌ها کد و خروجی هر سؤال را پیدا می‌کند و عددهایی که اینجا می‌نویسی را با خروجی نوت‌بوکت تطبیق می‌دهد.
- پاسخ‌ها: همین‌جا، عددها را از خروجی نوت‌بوک بنویس. پاسخ‌ها خودکار ذخیره می‌شوند و ارسال نهایی ثبت‌شدنی است؛ پاسخ دادن به هیچ سؤالی اجباری نیست و سؤال بی‌پاسخ نمره‌ای نمی‌گیرد.
- پیوست‌ها (چهار کارت): نوت‌بوک اجراشده، فایل دیتابیس day3.sqlite، test_predictions.jsonl و answerability_predictions.jsonl.
- تصحیح: هر مفهومی ۶۰٪ گزینه (با کد) و ۴۰٪ دلیل؛ هر عملی ۶۰٪ اجرا و نتیجه و ۴۰٪ تحلیل. فایل‌های پیش‌بینی با کد روی gold پنهان سنجیده می‌شوند؛ باقی را ایجنت تصحیح می‌خواند و با نوت‌بوک تو تطبیق می‌دهد. فایل دیتابیس‌ات را یک بررسی خودکار می‌خواند (جدول‌ها، کلیدهای خارجی، تعداد داده‌ها، بردارهای ۳۸۴بعدی، rollback) و بخش اجرایی سؤال‌های دیتابیس از روی همان نمره می‌گیرد؛ همان بررسی (check_day3_db.py) در بسته هست و می‌توانی پیش از ارسال امتحانش کنی. کد تو اجرا نمی‌شود. زمان و hash با مرجع تطبیق سخت داده نمی‌شود.
- قواعد: تنظیمات را فقط با train/dev انتخاب کن و پیش از ساختن فایل‌های test قفل کن. هیچ رمز، API key یا توکن واقعی در نوت‌بوک و فایل دیتابیس نگذار.
