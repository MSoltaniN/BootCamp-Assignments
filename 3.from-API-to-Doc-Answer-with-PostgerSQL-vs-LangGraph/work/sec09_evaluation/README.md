# بخش ۹ — ارزیابی بازیابی و کنترل نشت آزمون (۱۰ نمره)

> این بخش «دروازه»ی تکلیف است: تا قفل نکنی، حق ساختن فایل test نداری.

## چه چیزی ساخته می‌شود

| ماژول | نقش |
|---|---|
| `metrics.py` | Recall@k، MRR@k، nDCG@k در **سطح سند**، با حذف اسناد تکراری از رتبه‌بندی |
| `splits.py` | بارگذاری train/dev عمومی و test بدون برچسب |
| `compare.py` | مقایسهٔ lexical / dense / hybrid در k=3 با جدول و نمودار |
| `select.py` | انتخاب روش با MRR@3 روی dev و قاعدهٔ تساوی `lexical → dense → hybrid` |
| `lock.py` | نوشتن `artifacts/lock.json` با `config_hash`، `locked_at`، روش و آستانه |
| `predict.py` | ساخت فایل‌های test **پس از** قفل |
| `bootstrap.py` | بازهٔ ۹۵٪ با ۲۰۰۰ بازنمونه و seed ثابت |
| `answerability.py` | انتخاب آستانهٔ بیشترین cosine روی dev با بیشینه‌سازی balanced accuracy |
| `ablation.py` | مقایسهٔ chunk ۱۱۰ و ۲۲۰ توکنی روی شش پرسش dev |

## زیرسؤال‌ها

۹٫۱ توزیع split و پاسخ‌پذیری + تکرار دقیق (۰) · ۹٫۲ سه معیار روی دو مثال دستی · ۹٫۳ مقایسهٔ سه روش روی dev در k=3 · ۹٫۴ انتخاب با MRR@3 و قاعدهٔ تساوی · ۹٫۵ حساسیت k در ۱/۳/۵ · ۹٫۶ سه خطای اول dev · ۹٫۷ پیش‌بینی test · ۹٫۸ بازهٔ bootstrap · ۹٫۹ آستانهٔ پاسخ‌پذیری روی dev · ۹٫۱۰ فایل تصمیم‌پذیری test · ۹٫۱۱ ablation اندازهٔ chunk · ۹٫۱۲ گزارش ماشین‌خوان + سه ادعای پشتیبانی‌نشده

## خروجی

`deliverables/test_predictions.jsonl` (۳۰ خط) · `deliverables/answerability_predictions.jsonl` (۳۰ خط) · `artifacts/lock.json` · `artifacts/eval_report.json` · `artifacts/bootstrap.json`

## تعریف انجام‌شده

- `lock.json` **پیش از** اولین اجرای test نوشته شده (زمانش قابل بررسی است).
- هر فایل test دقیقاً ۳۰ خط دارد؛ `query_id`ها با split=test می‌خوانند؛ هر ردیف سه سند **متمایز** دارد.
- آستانهٔ پاسخ‌پذیری از dev آمده و بعد از ساخت فایل test تغییر نکرده.
- پاسخ‌ناپذیرها از میانگین متریک بازیابی حذف و جدا گزارش شده‌اند.

## تله‌ها

- چند chunk از یک سند در top-k را چند سند حساب نکن؛ رتبه‌بندی یکتا را صریح تعریف کن.
- Recall@k غیرنزولی است ولی MRR@k می‌تواند تغییر کند؛ دلیلش را در ۹٫۵ بنویس.
- ۲۴ پاسخ‌پذیر در dev، نمونهٔ کوچکی است؛ بازهٔ اطمینان را جدی بگیر و حجم کوچک را محدودیت بنویس.
- دیدن gold test یا تنظیم آستانه با آن = نقض صریح قید تکلیف.
