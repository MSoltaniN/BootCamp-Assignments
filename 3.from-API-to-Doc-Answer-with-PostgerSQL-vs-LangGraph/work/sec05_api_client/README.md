# بخش ۵ — کلاینت API و قرارداد خطا (۸ نمره)

## چه چیزی ساخته می‌شود

یک کلاینت و یک API محلی که با `FastAPI TestClient` آزموده می‌شود. هویت `X-User-ID` و پاسخ‌های ارائه‌دهنده **فقط fixture آموزشی‌اند**؛ این بخش ادعای ورود واقعی Google یا فراخوانی LLM پولی ندارد.

| ماژول          | نقش                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------ |
| `app.py`       | endpointهای پرونده/جستجو/جلسه با صفحه‌بندی پایدار و سقف `limit` در backend                 |
| `client.py`    | کلاینت با یک‌بار مصرف deadline و timeout جدا برای اتصال/خواندن                             |
| `retry.py`     | حداکثر سه تلاش، احترام به `Retry-After`، backoff برنامه‌ریزی‌شده **بدون خواب واقعی**       |
| `errors.py`    | envelope ثابت `{code, message, correlation_id}`                                            |
| `providers.py` | رابط ارائه‌دهنده با `base_url` + `model_id` قابل تعویض، آزمون‌شده با `httpx.MockTransport` |
| `cost.py`      | هزینهٔ فرضی ورودی/خروجی هر درخواست و جمع هر provider                                       |
