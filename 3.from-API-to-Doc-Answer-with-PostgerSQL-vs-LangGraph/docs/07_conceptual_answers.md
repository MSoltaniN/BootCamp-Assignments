# کارنامهٔ پاسخ‌های مفهومی — بخش‌های ۱ تا ۴

۴۸ زیرسؤال، هر کدام ۰٫۵ نمره (جمعاً ۲۴ نمره). وزن تصحیح: ۶۰٪ گزینه، ۴۰٪ دلیل.

قاعدهٔ نوشتن دلیل: یک جمله انتخاب + یک جمله **قید مسئله** را به انتخاب وصل کند. دلیل کتابی و تعریف عمومی نمرهٔ کامل نمی‌گیرد.

پس از پر شدن، همین جدول‌ها به سایت منتقل می‌شوند و گزینهٔ هر ردیف از بین گزینه‌های همان کارت انتخاب می‌شود.
