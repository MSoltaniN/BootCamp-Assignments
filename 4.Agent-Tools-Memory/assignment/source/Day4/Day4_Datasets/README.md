# داده‌های تمرین روز چهارم

تمام داده‌های این بسته مصنوعی‌اند و برای آموزش مهندسی ایجنت ساخته شده‌اند. هیچ فرد، رزومه، سابقهٔ کاری یا قیمت واقعی در داده‌ها وجود ندارد. ایمیل‌های example.invalid قابل ارسال نیستند.

۱. 01_HR: تعداد ۱۸۰ پروفایل، شواهد هر مهارت، و سیاست شش ترکیب tenant و دپارتمان. کار با این داده صرفاً ثبت مهارت مستند است؛ تصمیم استخدام، حقوق یا ارتقا خارج از دامنه است.
۲. 02_Context: تعداد ۹۶ سند و جدول برآورد بودجهٔ context. estimated_tokens برآورد آموزشی است و شمارش tokenizer واقعی نیست.
۳. 03_Requests: تعداد ۳۶۰ درخواست در ۱۸ خانوادهٔ قالب؛ train=۲۰۰، dev=۸۰، test=۸۰. ده خانواده مخصوص train، چهار خانواده مخصوص dev و چهار خانواده مخصوص test هستند. پس از حذف شمارهٔ نمایشی درخواست هم متن یکسانی بین splitها وجود ندارد. تکرار درون هر split برای تغییر دپارتمان و تعداد نمونه مجاز است. برچسب test در بستهٔ مدرس است و شناسه‌ها ویژگی مدل نیستند.
۴. 04_Memory: تعداد ۷۲۰ رخداد با روز نسبی، TTL و منشأ؛ بعضی رخدادها تأییدنشده‌اند. ایجاد حافظهٔ دائمی از دستور داخل سند مجاز نیست.
۵. 05_Tools: تعداد ۷۶ پاسخ شبیه‌سازی‌شدهٔ مدل و شش وضعیت HTTP برای آزمون حلقه و retry. این فایل خروجی LLM زنده نیست.
۶. 06_Security: تعداد ۱۲۰ حملهٔ مصنوعی در ده خانواده و ۶۰ متن بی‌خطر. برچسب‌ها برای red team آموزشی منتشر شده‌اند؛ این مجموعه آزمون نهایی مخفی نیست و معیار آن ادعای امنیت عمومی نمی‌سازد.
۷. 07_Evaluation: تعداد ۶۴۰ اجرای مصنوعی جفت‌شده از دو نسخه روی ۳۲۰ سناریو و ۲۵۶۰ span. دو worker موازی‌اند؛ جمع زمان spanها زمان دیواری نیست. success و policy_violation برچسب‌های fixture هستند و با اجرای واقعی نوت‌بوک اشتباه نشوند. قیمت‌ها فرض آموزشی با واحد دلار به ازای یک میلیون token هستند.
۸. 08_Rollout: تعداد ۶۰۰ درخواست شامل تحویل تکراری یک event_key برای تمرین صف و canary. تمام زمان‌ها نسبی و میلی‌ثانیه‌اند.

فرهنگ داده: tenant مرز سازمان، department مرز واحد، employee_id شناسهٔ مبهم فرد، evidence_id مرجع ادعا، verified تأیید منشأ، created_day و expires_day روز نسبی، split تقسیم آموزش/اعتبارسنجی/آزمون، variant نسخه، run_id اجرای یک نسخه، scenario_id شناسهٔ جفت مقایسه، correct_calls شمار فراخوانی درست از tool_calls است. گروه audit در gold مدرس فقط برای سنجش مصنوعی اختلاف کیفیت است و ورودی پروفایل‌سازی نیست.

بذر تولید 20261016 است. فایل‌های manifest.json اندازه و SHA-256 همهٔ داده‌ها را ثبت می‌کنند. اسلایدهای جلسهٔ چهارم مبنای سرفصل‌اند؛ داده‌ها تألیف آموزشی همین تمرین با مجوز CC0 هستند.
