## متن رسمی بخش

> sft_records_raw.jsonl و adapter_lab.npz؛ gold عددی test فقط در بستهٔ مدرس
> دادهٔ SFT را فقط ممیزی و پاک‌سازی می‌کنید. adapter واقعاً روی یک لایهٔ خطی ۱۶×۸ آموزش می‌بیند؛ این آزمایش fine-tune کامل LLM یا QLoRA نیست. پایه منجمد، scale=alpha/r با alpha=2، Adam و ۲۵۰ epoch و seed ثابت استفاده شود.
