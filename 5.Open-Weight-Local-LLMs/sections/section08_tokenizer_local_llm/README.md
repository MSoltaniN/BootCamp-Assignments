## متن رسمی بخش

> tokenizer_probes.jsonl، local_eval_dev.jsonl و Qwen2.5-0.5B-Instruct Q4_K_M
> llama-server واقعی روی loopback با CPU، چهار thread، یک slot و context=2048 اجرا کنید. مدل کوچک صرفاً آزمایش آموزشی است. هیچ سرویس ابری یا کلید پولی نیاز نیست. در هر سلول HTTP از context manager استفاده کنید تا حتی هنگام خطا فرایند سرور بسته شود.
