# تکلیف ۵: مدل‌های باز و اجرای محلی، ارزیابی و گردش کار امن

## شرح تکلیف

در این تکلیف مجوز و منشأ مدل، ظرفیت و هزینه، کوانتیزه‌سازی، اجرای واقعی دو quant محلی، ارزیابی فارسی و انگلیسی، صف و KV cache شبیه‌سازی‌شده، adapter کم‌رتبهٔ آموزشی و گردش کار امن HR را تمرین می‌کنی. ۱۲ بخش و ۱۴۴ زیرسؤال دارد: ۴۸ مفهومی با ۲۴ نمره و ۹۶ عملی با ۷۶ نمره؛ جمع ۱۰۰ نمره.دریافت و اجرا: بستهٔ دانشجو را از کارت «دیتاست» همین صفحه بگیر و START_HERE.md را بخوان. داده‌ها، صورت سؤال ASSIGNMENT.md، قالب نوت‌بوک و بررسی‌گر محلی در بسته‌اند. پاسخ را همین‌جا وارد کن؛ پاسخ‌ها خودکار ذخیره می‌شوند و ارسال نهایی از همین صفحه است.نوت‌بوک: برای هر زیرسؤال سه سلول با عنوان «زیرسؤال N.M» نگه دار: صورت سؤال، کد انگلیسی و خروجی اجرا، تحلیل فارسی راست‌به‌چپ. Student_Template.ipynb این ساختار را آماده دارد.پیوست‌ها: نوت‌بوک اجراشده و ZIP شواهد، هرکدام تا ۲۵ MiB (مجموع تا ۵۰ MiB). ZIP شامل کد، README بازاجرا، SQLite، predictionها و گزارش‌های عملی است؛ فهرست دقیق در START_HERE.md آمده. داده‌های مشترک، وزن‌ها و باینری را دوباره بارگذاری نکن.تصحیح: هر مفهومی ۶۰٪ گزینه با کد و ۴۰٪ دلیل؛ هر عملی ۶۰٪ روش، کد و خروجی و ۴۰٪ تحلیل دارد. ایجنت کد و خروجی نوت‌بوک و گزارش‌های ZIP را می‌خواند؛ کد تو اجرا نمی‌شود. checker محلی جای تأیید مستقل مدرس را نمی‌گیرد. هیچ سؤال اجباری نیست و سؤال خالی نمره‌ای نمی‌گیرد.قواعد: تنظیمات را فقط با train/dev انتخاب کن؛ test و پاسخ مرجع خصوصی‌اند. در فیلد معیار خصوصی «خصوصی» بنویس. زمان و hash وابسته به پیاده‌سازی با مرجع تطبیق سخت ندارند. هیچ رمز یا API key واقعی در فایل‌ها نگذار.منابع روز پنجم: مدل‌ها داخل ZIP نیستند. download_resources.py دو GGUF ثابت (حدود ۱٫۱۷ GB) و موتور Windows x64 را با hash دریافت می‌کند. برای Linux/macOS، LLAMA_SERVER_PATH را به llama-server بومی بده. حدود ۲ GB RAM آزاد به‌علاوهٔ محیط پایتون و داده‌ها توصیهٔ آزمایش است.مرز شواهد: دو quant مدل Qwen2.5-0.5B-Instruct و HTTP محلی و adapter خطی آموزشی در پاسخ مرجع اجرا شده‌اند؛ صف و KV cache شبیه‌سازی‌اند و fine-tune کامل LLM، QLoRA، vLLM و MoE بزرگ اجرا نشده‌اند.
