**تحلیل:** chunking با همان تنظیمات دوباره اجرا شد و **ترتیب و مقدار** هر ۱۲۸۲ شناسه یکسان ماند.

شناسه از چهار جزء ساخته می‌شود: `doc_id + version + (start, end) + hash(content)`. هر جزء لازم است:

| جزء               | اگر نبود چه می‌شد                                 |
| ----------------- | ------------------------------------------------- |
| `doc_id`          | دو سند مختلف با متن یکسان شناسهٔ یکسان می‌گرفتند  |

| بازهٔ `start/end` | دو chunk هم‌محتوا در جای مختلف یک شناسه می‌گرفتند |
| `content_hash`    | تغییر محتوا با همان بازه شناسه را عوض نمی‌کرد     |

بدون پایداری، هر اجرای دوبارهٔ ایندکس یک مجموعهٔ جدید می‌ساخت و ارجاع‌های قبلی به chunkهای قدیمی می‌شکست.
